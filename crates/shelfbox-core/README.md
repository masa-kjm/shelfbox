# shelfbox-core

Core library for [shelfbox](https://github.com/masa-kjm/shelfbox), a command-line tool that keeps personal files—AI agent instructions and skills, notes, scripts, and machine-local configuration—visible in your editor but out of Git. It stores canonical content in a local store and helps restore it after recloning or in a worktree.

Most users should install the CLI instead:

```sh
cargo install shelfbox --locked
```
